# Northwind Cloud Support Playbook (synthetic)

## Common tickets and recommended replies
### "I was charged twice"
1. Look up both charges in Stripe; if both are real, refund the duplicate immediately.
2. Reply within one hour. Template priority: high.

### "Report didn't generate on Friday"
1. Check the reports job status at reports-jobs dashboard.
2. If a bug, link the issue number and state honestly that it is a bug we introduced,
   what was fixed, and when numbers will be correct again. Never overpromise a date.

### "Can I change plan mid-cycle"
Yes. We pro-rate the difference and apply it on the next invoice.

## Response time targets
- First reply: under 1.5 hours (median measured weekly).
- Resolution: 8 working hours for billing, 2 working days for API bugs.

## Tone guide
- Acknowledge the problem in sentence 1. State the fix in sentence 2.
- Offer a concrete next step ("any time this week", "tomorrow at 10am").
- Sign off with "Thanks" then the agent's name.
